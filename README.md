# Adaptive Scanning Interfaces

Interface-only ROS 2 package shared by the Adaptive Scanning Common and Robot
containers. It intentionally contains no nodes, launch files, robot assets, or
application implementation.

## Interfaces

- `ExecuteJoint`
- `ExecuteWaypoints`
- `LookAtWaypoints`
- `ParallelPlanningAndExecution`
- `RunHandeyeCalibration`
- `WaypointPlannerStage`
- `RobotHardwareStatus`
- `ExecuteJoint` service (legacy compatibility)
Interface Definition for Adaptive Scanning
